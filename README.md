# 🐉 Dragon Co. Website

A responsive, fantasy-themed website for **Dragon Co.**, a fictional company offering dragons of all kinds.  
This project focuses on clean HTML/CSS structure, responsive layouts, and playful visual effects.

---

## ✨ Features

- Fully responsive header and navigation
- Animated gradient background
- Interactive navigation buttons with sparkle / twinkle hover effects
- Responsive layouts using Flexbox and CSS Grid
- Mobile-friendly design
- Custom typography using Google Fonts
- Themed pages:
  - Home
  - Browse Dragons
  - Request a Dragon
  - About
  - Testimonials

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
  - Flexbox
  - CSS Grid
  - Media Queries
  - `clamp()` for responsive typography
  - Keyframe animations
- **Google Fonts** (Carattere)

No JavaScript or frameworks were used — this site is built with pure HTML and CSS.

---

## 📱 Responsive Design

The site is designed to work smoothly across:
- Desktop
- Tablet
- Mobile devices

Key responsive behaviors:
- Navigation links wrap or stack on smaller screens
- Header height adjusts automatically based on content
- Images scale fluidly using `object-fit` and viewport units
- Cards and grids reflow naturally on mobile
